# ⚔️ Clash of Java

Un minijuego de estrategia por consola escrito en Java, inspirado en la gestión de aldeas. Administra tus recursos, mejora tus defensas y pon a prueba tu suerte en el campo de batalla.

## 🎮 Características principales

* **Gestión de Recursos:** Almacena y recolecta Oro y Elixir de forma interactiva (¡solo pulsando `INTRO`!).
* **Mejora de Estructuras:** Sube de nivel tu Ayuntamiento y tu Cañón (hasta el nivel máximo de 10). El coste escala dinámicamente según el nivel actual.
* **Sistema de Batallas:** Invierte 10.000 de Elixir para lanzar un ataque. La probabilidad de victoria depende directamente del nivel de tu Cañón (30% base + 5% por nivel). ¡Si ganas, te llevas un botín de 90.000 de cada recurso!
